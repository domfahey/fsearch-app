# FSearch for Mac v1 (launcher panel) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed, notarized Mac app whose global-hotkey launcher panel searches the whole disk by name and inside files, through a bundled fsearch daemon, with first-run onboarding and a debug mode.

**Architecture:** All logic that doesn't need AppKit lives in a Swift package, `FSearchKit`: the socket client, wire types, search state, the key handling as a pure function, onboarding rules, recents, the search log and editor commands. It builds and tests with `swift test`. A thin macOS app target (generated by XcodeGen) adds the floating `NSPanel`, the SwiftUI views, the menu bar, `SMAppService`, Quick Look and Finder actions. The engine is the existing `fsearch` daemon binary, bundled in the app and spoken to over its JSON-lines Unix socket.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI plus AppKit, Swift Testing, XcodeGen, [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts) (hotkey and recorder), [Sparkle 2](https://github.com/sparkle-project/Sparkle) (updates), the fsearch Rust daemon (bundled binary).

**Spec:** `docs/superpowers/specs/2026-10-10-fsearch-app-design.md`

## Global Constraints

- macOS 14 (Sonoma) and later; universal binary (arm64 and x86_64).
- Signed with an Apple Developer ID and notarized; never ship an ad-hoc-signed build to users.
- The daemon socket is `~/Library/Application Support/FSearch/fsearch.sock`; the data folder is `~/Library/Application Support/FSearch`.
- The daemon runs as `fsearch serve`. Requests are one JSON object per line, answers one per line, in order per connection.
- Name results: up to 50 (`"limit": 50`). Content and symbol searches use a 250 ms budget (`"budget_ms": 250`).
- Default hotkey ⌥ Space. Recents: the last 8 files opened from the panel. Resume window: 60 seconds.
- Search log: off unless debug mode is on, stored only on this Mac, capped at 10,000 entries, with a Clear button.
- No test, script or tool may touch the user's real index, data folder, LaunchAgents or `~/.local/bin`. Integration tests use a temp `HOME` and `FSEARCH_ROOT`.
- No Raycast name, icon, logo, colours or assets anywhere in the app. Follow the layout pattern only.
- `FSearchKit` tasks need only the Swift toolchain (`swift test`). App-target tasks (Tasks 0, 9–15) need **Xcode 16 or later** selected as the active developer directory. Xcode is installed at `/Applications/Xcode.app`, but the active directory is currently the Command Line Tools: run `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` once before Task 0 (check with `xcodebuild -version`).

## Review Focus

1. **Paths with spaces, emoji or non-ASCII** (`~/Downloads/🏡 105 25Th Street So, Brigantine, NJ 08203 _ NJPropertyRecords.pdf`): open, reveal, copy path and open-at-line must work unchanged. Pinned in Task 7 (args are never shell-joined) and Task 11 (URL building).
2. **Very fast typing** (20 keystrokes in 100 ms): the panel must only ever show results for the latest query, never a slower earlier answer. Pinned in Task 4 (`latestWins` test).
3. **Daemon gone mid-session** (crashed, killed, socket file left behind): the next search must fail quickly with a clear state and reconnect when the daemon is back, never hang the panel. Pinned in Task 2 (timeout and reconnect tests).
4. **Content queries containing filters or spaces** (`hello world ext:rs`): the pattern is `hello world`, the filter is `ext:rs`. The daemon's own syntax would make `world` a name filter. Pinned in Task 3 (`QuerySplit` tests).
5. **First run while still indexing:** search must show "Indexing your disk…" and retry, not an empty list or an error. Pinned in Task 4 (indexing state) and Task 13 (message mapping).

```swift
import Foundation

public enum GrepMode: String, Sendable { case literal, regex, symbol }

/// One request to the daemon. Name search is the default op.
public enum Request: Sendable {
    case search(q: String, limit: Int)
    case grep(q: String, pattern: String, mode: GrepMode, budgetMs: Int)
    case status
    case ping
    /// Compact and save the index soon (the daemon answers "scheduled").
    case save

    /// One JSON line, without the newline.
    public func json(id: Int) -> Data {
        var o: [String: Any] = ["id": id]
        switch self {
        case let .search(q, limit): o["q"] = q; o["limit"] = limit
        case let .grep(q, pattern, mode, budget):
            o["op"] = "grep"; o["q"] = q; o["pattern"] = pattern; o["mode"] = mode.rawValue; o["budget_ms"] = budget
        case .status: o["op"] = "status"
        case .ping: o["op"] = "ping"
        case .save: o["op"] = "save"
        }
        return try! JSONSerialization.data(withJSONObject: o, options: [.sortedKeys])
    }
}

public struct Hit: Decodable, Equatable, Sendable {
    public let path: String
    public let kind: String
    public let size: UInt64
    public let mtime: UInt32
    public let score: Int32
    public init(path: String, kind: String, size: UInt64, mtime: UInt32, score: Int32) {
        (self.path, self.kind, self.size, self.mtime, self.score) = (path, kind, size, mtime, score)
    }
}

public struct SearchReply: Decodable, Equatable, Sendable {
    public let tookUs: UInt64
    public let hits: [Hit]
}

public struct Match: Decodable, Equatable, Sendable {
    public let line: Int
    public let text: String
    public init(line: Int, text: String) { (self.line, self.text) = (line, text) }
}

public struct FileMatches: Decodable, Equatable, Sendable {
    public let path: String
    public let matches: [Match]
}

public struct GrepReply: Decodable, Equatable, Sendable {
    public let tookUs: UInt64
    public let source: String
    public let candidates: Int
    public let read: Int
    public let complete: Bool
    public let files: [FileMatches]
}

public struct DaemonStatus: Decodable, Equatable, Sendable {
    public let entries, dirs, overlay, removed: Int
    public let eventId: UInt64
    public let indexBytes, contentDocs, contentSegments, contentBytes, contentPending: Int
    public let fullDiskAccess, owner: Bool
}

public enum DaemonError: Error, Equatable, Sendable {
    /// The first index isn't built yet (the daemon says "indexing ...").
    case indexing(String)
    /// Any other error the daemon reports, e.g. a bad regex or filter.
    case daemon(String)
    case disconnected
    case timeout
    case badReply(String)
}

private struct Envelope: Decodable { let ok: Bool; let error: String? }

/// Decode one reply line, turning `{"ok": false, "error": ...}` into a DaemonError.
public func decodeReply<T: Decodable>(_ line: Data, as: T.Type) throws -> T {
    let dec = JSONDecoder()
    dec.keyDecodingStrategy = .convertFromSnakeCase
    guard let env = try? dec.decode(Envelope.self, from: line) else {
        throw DaemonError.badReply(String(decoding: line.prefix(200), as: UTF8.self))
    }
    if !env.ok {
        let msg = env.error ?? "error"
        throw msg.hasPrefix("indexing") ? DaemonError.indexing(msg) : DaemonError.daemon(msg)
    }
    do { return try dec.decode(T.self, from: line) }
    catch { throw DaemonError.badReply(String(describing: error)) }
}
```

### Task 2: LineSocket and DaemonClient

A blocking, newline-framed Unix-socket transport, wrapped in an async client. Each `DaemonClient` owns one connection and sends one request at a time (the daemon answers each connection in order), so replies can't cross. Reads time out, and a broken connection is re-dialled on the next request.

**Files:**
- Create: `Packages/FSearchKit/Sources/FSearchKit/LineSocket.swift`
- Create: `Packages/FSearchKit/Sources/FSearchKit/DaemonClient.swift`
- Create: `Packages/FSearchKit/Tests/FSearchKitTests/FakeDaemon.swift`
- Test: `Packages/FSearchKit/Tests/FSearchKitTests/DaemonClientTests.swift`

**Interfaces:**
- Consumes: `Request`, `decodeReply`, `SearchReply`, `GrepReply`, `DaemonStatus`, `DaemonError` (Task 1).
- Produces:
  - `protocol SearchBackend: Sendable { func search(_ q: String, limit: Int) async throws -> SearchReply; func grep(q: String, pattern: String, mode: GrepMode) async throws -> GrepReply; func status() async throws -> DaemonStatus; func ping() async throws }`
  - `final class DaemonClient: SearchBackend` with `init(socketPath: String, timeout: TimeInterval = 5)` and `func save() async throws`
  - `static let DaemonClient.defaultSocketPath: String` (`~/Library/Application Support/FSearch/fsearch.sock`)

- [ ] **Step 1: Write the test helper `FakeDaemon.swift`.** An in-process Unix-socket server that answers each request line with whatever a closure returns. A closure returning `nil` makes it read and say nothing, to simulate a hung daemon.

```swift
import Darwin
import Foundation

/// A scripted daemon on a temp Unix socket.
final class FakeDaemon: @unchecked Sendable {
    let path: String
    private var fd: Int32 = -1
    private let reply: @Sendable ([String: Any]) -> [String: Any]?
    private(set) var requests: [[String: Any]] = []
    private let lock = NSLock()

    init(reply: @escaping @Sendable ([String: Any]) -> [String: Any]?) {
        path = NSTemporaryDirectory() + "fsk-\(UUID().uuidString.prefix(8)).sock"
        self.reply = reply
        start()
    }

    private func start() {
        unlink(path)
        fd = socket(AF_UNIX, SOCK_STREAM, 0)
        var addr = sockaddr_un()
        addr.sun_family = sa_family_t(AF_UNIX)
        withUnsafeMutableBytes(of: &addr.sun_path) { p in _ = path.withCString { strncpy(p.baseAddress!.assumingMemoryBound(to: CChar.self), $0, p.count - 1) } }
        let len = socklen_t(MemoryLayout<sockaddr_un>.size)
        withUnsafePointer(to: &addr) { $0.withMemoryRebound(to: sockaddr.self, capacity: 1) { _ = bind(fd, $0, len) } }
        listen(fd, 8)
        let listener = fd
        Thread.detachNewThread { [self] in
            while true {
                let c = accept(listener, nil, nil)
                if c < 0 { return }
                Thread.detachNewThread { self.serve(c) }
            }
        }
    }

    private func serve(_ c: Int32) {
        var buf = Data()
        var chunk = [UInt8](repeating: 0, count: 4096)
        while true {
            let n = read(c, &chunk, chunk.count)
            if n <= 0 { close(c); return }
            buf.append(contentsOf: chunk[0..<n])
            while let nl = buf.firstIndex(of: UInt8(ascii: "\n")) {
                let line = buf[buf.startIndex..<nl]
                buf.removeSubrange(buf.startIndex...nl)
                let req = (try? JSONSerialization.jsonObject(with: line)) as? [String: Any] ?? [:]
                lock.lock(); requests.append(req); lock.unlock()
                guard var out = reply(req) else { continue }
                out["id"] = req["id"]
                var data = try! JSONSerialization.data(withJSONObject: out)
                data.append(UInt8(ascii: "\n"))
                _ = data.withUnsafeBytes { write(c, $0.baseAddress, data.count) }
            }
        }
    }

    /// Stop accepting and remove the socket file (a "crashed" daemon).
    func stop() { close(fd); unlink(path) }
    deinit { stop() }
}
```

```swift
import Darwin
import Foundation

/// A blocking, newline-framed Unix-socket connection. Not thread-safe: the
/// owner serializes calls.
final class LineSocket {
    private var fd: Int32 = -1
    private var buffer = Data()
    let path: String
    let timeout: TimeInterval

    init(path: String, timeout: TimeInterval) { (self.path, self.timeout) = (path, timeout) }
    deinit { close() }

    func close() {
        if fd >= 0 { Darwin.close(fd) }
        fd = -1
        buffer.removeAll()
    }

    private func connectIfNeeded() throws {
        if fd >= 0 { return }
        let s = socket(AF_UNIX, SOCK_STREAM, 0)
        guard s >= 0 else { throw DaemonError.disconnected }
        var addr = sockaddr_un()
        addr.sun_family = sa_family_t(AF_UNIX)
        let fits = path.utf8.count < MemoryLayout.size(ofValue: addr.sun_path)
        guard fits else { Darwin.close(s); throw DaemonError.disconnected }
        withUnsafeMutableBytes(of: &addr.sun_path) { p in _ = path.withCString { strncpy(p.baseAddress!.assumingMemoryBound(to: CChar.self), $0, p.count - 1) } }
        var tv = timeval(tv_sec: Int(timeout), tv_usec: Int32((timeout - Double(Int(timeout))) * 1_000_000))
        setsockopt(s, SOL_SOCKET, SO_RCVTIMEO, &tv, socklen_t(MemoryLayout<timeval>.size))
        setsockopt(s, SOL_SOCKET, SO_SNDTIMEO, &tv, socklen_t(MemoryLayout<timeval>.size))
        var one: Int32 = 1
        setsockopt(s, SOL_SOCKET, SO_NOSIGPIPE, &one, socklen_t(MemoryLayout<Int32>.size))
        let len = socklen_t(MemoryLayout<sockaddr_un>.size)
        let r = withUnsafePointer(to: &addr) { $0.withMemoryRebound(to: sockaddr.self, capacity: 1) { connect(s, $0, len) } }
        guard r == 0 else { Darwin.close(s); throw DaemonError.disconnected }
        fd = s
    }

    /// Send one line and read one line back. Any failure closes the
    /// connection, so the next call dials again.
    func roundTrip(_ line: Data) throws -> Data {
        try connectIfNeeded()
        do {
            var out = line
            out.append(UInt8(ascii: "\n"))
            let sent = out.withUnsafeBytes { write(fd, $0.baseAddress, out.count) }
            guard sent == out.count else { throw DaemonError.disconnected }
            return try readLine()
        } catch {
            close()
            throw error
        }
    }

    private func readLine() throws -> Data {
        var chunk = [UInt8](repeating: 0, count: 64 * 1024)
        while true {
            if let nl = buffer.firstIndex(of: UInt8(ascii: "\n")) {
                let line = buffer[buffer.startIndex..<nl]
                buffer.removeSubrange(buffer.startIndex...nl)
                return Data(line)
            }
            let n = read(fd, &chunk, chunk.count)
            if n > 0 { buffer.append(contentsOf: chunk[0..<n]); continue }
            if n < 0 && (errno == EAGAIN || errno == EWOULDBLOCK) { throw DaemonError.timeout }
            throw DaemonError.disconnected
        }
    }
}
```

```swift
import Foundation

/// What the search UI needs from a daemon (a fake in tests).
public protocol SearchBackend: Sendable {
    func search(_ q: String, limit: Int) async throws -> SearchReply
    func grep(q: String, pattern: String, mode: GrepMode) async throws -> GrepReply
    func status() async throws -> DaemonStatus
    func ping() async throws
}

/// One connection to the fsearch daemon. Requests go out one at a time on a
/// serial queue: the daemon answers a connection in order, so replies never
/// cross between callers.
public final class DaemonClient: SearchBackend, @unchecked Sendable {
    public static var defaultSocketPath: String {
        NSHomeDirectory() + "/Library/Application Support/FSearch/fsearch.sock"
    }

    private let socket: LineSocket
    private let queue = DispatchQueue(label: "fsearch.client")
    private var nextId = 0

    public init(socketPath: String = DaemonClient.defaultSocketPath, timeout: TimeInterval = 5) {
        socket = LineSocket(path: socketPath, timeout: timeout)
    }

    private func call<T: Decodable>(_ req: Request, as: T.Type) async throws -> T {
        try await withCheckedThrowingContinuation { cont in
            queue.async { [self] in
                nextId += 1
                do { cont.resume(returning: try decodeReply(try socket.roundTrip(req.json(id: nextId)), as: T.self)) }
                catch { cont.resume(throwing: error) }
            }
        }
    }

    public func search(_ q: String, limit: Int) async throws -> SearchReply {
        try await call(.search(q: q, limit: limit), as: SearchReply.self)
    }

    public func grep(q: String, pattern: String, mode: GrepMode) async throws -> GrepReply {
        try await call(.grep(q: q, pattern: pattern, mode: mode, budgetMs: 250), as: GrepReply.self)
    }

    public func status() async throws -> DaemonStatus {
        try await call(.status, as: DaemonStatus.self)
    }

    private struct Pong: Decodable {}
    public func ping() async throws { _ = try await call(.ping, as: Pong.self) }

    /// Ask the daemon to compact and save its index (debug mode's "Save Now").
    public func save() async throws { _ = try await call(.save, as: Pong.self) }
}
```

```swift
/// The real fsearch daemon, isolated: temp HOME and FSEARCH_ROOT. Never the
/// user's index.
final class RealDaemon {
    let home: URL
    let root: URL
    let process = Process()
    var socketPath: String { home.path + "/Library/Application Support/FSearch/fsearch.sock" }

    static var binary: URL? {
        let p = URL(fileURLWithPath: #filePath).deletingLastPathComponent()
            .appendingPathComponent("../../../../Vendor/fsearch").standardized
        return FileManager.default.isExecutableFile(atPath: p.path) ? p : nil
    }

    init(files: [String: String]) throws {
        home = URL(fileURLWithPath: "/private/tmp/fsk-\(UUID().uuidString.prefix(6))")
        root = home.appendingPathComponent("root")
        for (rel, body) in files {
            let f = root.appendingPathComponent(rel)
            try FileManager.default.createDirectory(at: f.deletingLastPathComponent(), withIntermediateDirectories: true)
            try body.write(to: f, atomically: true, encoding: .utf8)

        process.executableURL = RealDaemon.binary!
        process.arguments = ["serve"]
        process.environment = ["HOME": home.path, "FSEARCH_ROOT": root.path]
        process.standardOutput = FileHandle.nullDevice
        process.standardError = FileHandle.nullDevice
        try process.run()
    }

    deinit {
        process.terminate()
        process.waitUntilExit()
        try? FileManager.default.removeItem(at: home)
    }
```

```swift
/// Content queries: the typed text is the pattern, except fsearch filters
/// (`ext:rs`, `in:~/x`, `mtime:<7d`), which narrow the files searched.
/// Sending the text as `grep:...` instead would turn a second word into a
/// name filter.
public enum QuerySplit {
    static let keys: Set<String> = ["ext", "type", "kind", "in", "size", "mtime", "modified", "re", "path", "limit"]

    public static func split(_ query: String) -> (pattern: String, filters: String) {
        var pattern: [Substring] = [], filters: [Substring] = []
        for word in query.split(separator: " ", omittingEmptySubsequences: true) {
            if let colon = word.firstIndex(of: ":"), keys.contains(String(word[..<colon])), word.index(after: colon) < word.endIndex {
                filters.append(word)
            } else {
                pattern.append(word)
            }
        }
        return (pattern.joined(separator: " "), filters.joined(separator: " "))
    }
}
```

```swift
import Foundation
import Observation

public enum SearchMode: Equatable, Sendable { case names, content, symbols }

public enum ResultItem: Equatable, Identifiable, Sendable {
    case file(Hit)
    case line(path: String, match: Match)

    public var path: String {
        switch self { case let .file(h): h.path; case let .line(p, _): p }
    }
    public var id: String {
        switch self { case let .file(h): h.path; case let .line(p, m): "\(p):\(m.line)" }
    }
}

public enum SearchPhase: Equatable, Sendable { case idle, loading, results, indexing, failed(DaemonError) }

/// One search box. Each refresh is a generation; only the newest one may
/// publish, so slow answers to older queries are dropped.
@MainActor @Observable
public final class SearchModel {
    public struct LogEntry: Equatable, Sendable {
        public let query: String
        public let mode: SearchMode
        public let resultCount: Int
        public let tookUs: UInt64?
        public let roundTripMs: Double
        public let error: String?
    }

    public var query = ""
    public var mode: SearchMode = .names
    public private(set) var items: [ResultItem] = []
    public private(set) var phase: SearchPhase = .idle
    public private(set) var lastTookUs: UInt64?
    @ObservationIgnored public var onSearched: ((LogEntry) -> Void)?

    @ObservationIgnored private let names: SearchBackend
    @ObservationIgnored private let content: SearchBackend
    @ObservationIgnored private var generation = 0

    public init(names: SearchBackend, content: SearchBackend) {
        self.names = names
        self.content = content
    }

    public func refresh() async {
        generation += 1
        let gen = generation, q = query, mode = self.mode
        if q.trimmingCharacters(in: .whitespaces).isEmpty {
            (items, phase, lastTookUs) = ([], .idle, nil)
            return
        }
        phase = .loading
        let started = Date()
        do {
            let (found, took) = try await run(q, mode)
            guard gen == generation else { return }
            (items, phase, lastTookUs) = (found, .results, took)
            report(q, mode, found.count, took, started, nil)
        } catch let e as DaemonError {
            guard gen == generation else { return }
            items = []
            if case .indexing = e { phase = .indexing } else { phase = .failed(e) }
            report(q, mode, 0, nil, started, String(describing: e))
        } catch {
            guard gen == generation else { return }
            (items, phase) = ([], .failed(.badReply(String(describing: error))))
        }
    }

    private func run(_ q: String, _ mode: SearchMode) async throws -> ([ResultItem], UInt64) {
        switch mode {
        case .names:
            let r = try await names.search(q, limit: 50)
            return (r.hits.map(ResultItem.file), r.tookUs)
        case .content, .symbols:
            let (pattern, filters) = QuerySplit.split(q)
            let r = try await content.grep(q: filters, pattern: pattern, mode: mode == .symbols ? .symbol : .literal)
            return (r.files.flatMap { f in f.matches.map { ResultItem.line(path: f.path, match: $0) } }, r.tookUs)
        }
    }

    private func report(_ q: String, _ mode: SearchMode, _ n: Int, _ took: UInt64?, _ started: Date, _ err: String?) {
        onSearched?(LogEntry(query: q, mode: mode, resultCount: n, tookUs: took, roundTripMs: Date().timeIntervalSince(started) * 1000, error: err))
    }
}
```

```swift
import Foundation

public enum PanelKey: Equatable, Sendable {
    case up, down, enter, cmdEnter, cmdY, cmdShiftC, cmdDigit(Int), cmdK, escape, backspaceOnEmpty
}

public enum PanelEffect: Equatable, Sendable {
    case none, open(Int), reveal(Int), quickLook(Int), copyPath(Int), showActions(Int), hide
}

public struct PanelState: Equatable, Sendable {
    public var query: String
    public var mode: SearchMode
    public var selection: Int
    public var count: Int
    public init(query: String = "", mode: SearchMode = .names, selection: Int = 0, count: Int = 0) {
        (self.query, self.mode, self.selection, self.count) = (query, mode, selection, count)
    }
}

/// What a key does to the panel. No UI involved, so every binding is testable.
public func reduce(_ s: inout PanelState, _ key: PanelKey) -> PanelEffect {
    let has = s.count > 0
    switch key {
    case .up: s.selection = max(0, s.selection - 1); return .none
    case .down: s.selection = min(max(0, s.count - 1), s.selection + 1); return .none
    case .enter: return has ? .open(s.selection) : .none
    case .cmdEnter: return has ? .reveal(s.selection) : .none
    case .cmdY: return has ? .quickLook(s.selection) : .none
    case .cmdShiftC: return has ? .copyPath(s.selection) : .none
    case .cmdK: return has ? .showActions(s.selection) : .none
    case let .cmdDigit(n): return (1...9).contains(n) && n <= s.count ? .open(n - 1) : .none
    case .escape:
        // Clear the query, then drop the content/symbols chip, then hide.
        if !s.query.isEmpty { s.query = ""; s.selection = 0; return .none }
        if s.mode != .names { s.mode = .names; return .none }
        return .hide
    case .backspaceOnEmpty:
        s.mode = .names
        return .none
    }
}

/// Reopening within a minute resumes where you left off.
public struct PanelSession: Sendable {
    public static let resumeWindow: TimeInterval = 60
    private var last: (PanelState, Date)?
    public init() {}
    public mutating func hidden(_ s: PanelState, at t: Date) { last = (s, t) }
    public func opened(at t: Date) -> PanelState {
        if let (s, at) = last, t.timeIntervalSince(at) <= Self.resumeWindow { return s }
        return PanelState()
    }
}
```

```swift
public final class Recents: @unchecked Sendable {
    public static let limit = 8
    private let defaults: UserDefaults
    private let exists: (String) -> Bool
    private let key = "recentPaths"

    public init(defaults: UserDefaults = .standard, exists: @escaping (String) -> Bool = { FileManager.default.fileExists(atPath: $0) }) {
        self.defaults = defaults
        self.exists = exists
    }

    public func opened(_ path: String) {

        list.removeAll { $0 == path }
        list.insert(path, at: 0)
        defaults.set(Array(list.prefix(Self.limit * 2)), forKey: key)
    }

    public var paths: [String] {
        Array((defaults.stringArray(forKey: key) ?? []).filter(exists).prefix(Self.limit))
    }
}
```

```swift
import Foundation

/// Editors that can open a file at a line, for content results.
public enum Editor: String, CaseIterable, Sendable {
    case vscode, cursor, zed, sublime, bbedit, xcode

    public var bundleId: String {
        switch self {
        case .vscode: "com.microsoft.VSCode"
        case .cursor: "com.todesktop.230313mzl4w4u92"
        case .zed: "dev.zed.Zed"
        case .sublime: "com.sublimetext.4"
        case .bbedit: "com.barebones.bbedit"
        case .xcode: "com.apple.dt.Xcode"
        }
    }

    public var displayName: String {
        switch self {
        case .vscode: "Visual Studio Code"
        case .cursor: "Cursor"
        case .zed: "Zed"
        case .sublime: "Sublime Text"
        case .bbedit: "BBEdit"
        case .xcode: "Xcode"
        }
    }
}

public struct EditorCommand: Equatable, Sendable {
    public let executable: String
    public let arguments: [String]
}

/// The command that opens `path` at `line`. Arguments go to the process as
/// an array (never a shell string), so any path needs no quoting.
public func openAtLine(_ e: Editor, appURL: URL, path: String, line: Int) -> EditorCommand {
    let app = appURL.path
    switch e {
    case .vscode: return EditorCommand(executable: app + "/Contents/Resources/app/bin/code", arguments: ["-g", "\(path):\(line)"])
    case .cursor: return EditorCommand(executable: app + "/Contents/Resources/app/bin/cursor", arguments: ["-g", "\(path):\(line)"])
    case .zed: return EditorCommand(executable: app + "/Contents/MacOS/cli", arguments: ["\(path):\(line)"])
    case .sublime: return EditorCommand(executable: app + "/Contents/SharedSupport/bin/subl", arguments: ["\(path):\(line)"])
    case .bbedit: return EditorCommand(executable: app + "/Contents/Helpers/bbedit_tool", arguments: ["+\(line)", path])
    case .xcode: return EditorCommand(executable: "/usr/bin/xed", arguments: ["-l", "\(line)", path])
    }
}

/// Editors present on this Mac. `lookup` maps a bundle id to its app URL
/// (NSWorkspace.urlForApplication(withBundleIdentifier:) in the app).
public func installedEditors(lookup: (String) -> URL?) -> [(Editor, URL)] {
    Editor.allCases.compactMap { e in lookup(e.bundleId).map { (e, $0) } }
}
```

```swift
import Foundation

/// Debug mode's search log: JSON lines, newest last, capped. Stays on this Mac.
public final class SearchLog: @unchecked Sendable {
    public struct Record: Codable, Equatable, Sendable {
        public let time: Date
        public let query: String
        public let mode: String
        public let results: Int
        public let tookUs: UInt64?
        public let roundTripMs: Double
        public let error: String?
    }

    public let file: URL
    private let cap: Int
    private let lock = NSLock()

    public init(file: URL = FileManager.default.homeDirectoryForCurrentUser.appendingPathComponent("Library/Logs/FSearch/searches.jsonl"), cap: Int = 10_000) {
        self.file = file
        self.cap = cap
    }

    private static func mode(_ m: SearchMode) -> String {
        switch m { case .names: "names"; case .content: "content"; case .symbols: "symbols" }
    }

    public func append(_ e: SearchModel.LogEntry, at t: Date) {
        lock.lock(); defer { lock.unlock() }
        let r = Record(time: t, query: e.query, mode: Self.mode(e.mode), results: e.resultCount, tookUs: e.tookUs, roundTripMs: e.roundTripMs, error: e.error)
        let enc = JSONEncoder(); enc.dateEncodingStrategy = .secondsSince1970
        var all = read()
        all.append(r)
        // Trim in batches, once 10% over the cap (every append for tiny caps).
        if all.count > cap + cap / 10 { all = Array(all.suffix(cap)) }
        try? FileManager.default.createDirectory(at: file.deletingLastPathComponent(), withIntermediateDirectories: true)
        let body = all.compactMap { try? enc.encode($0) }.map { String(decoding: $0, as: UTF8.self) }.joined(separator: "\n") + "\n"
        try? body.write(to: file, atomically: true, encoding: .utf8)
    }

    public func entries() -> [Record] {
        lock.lock(); defer { lock.unlock() }
        return Array(read().suffix(cap))
    }

    public func clear() {
        lock.lock(); defer { lock.unlock() }
        try? FileManager.default.removeItem(at: file)
    }

    private func read() -> [Record] {
        guard let data = try? Data(contentsOf: file) else { return [] }
        let dec = JSONDecoder(); dec.dateDecodingStrategy = .secondsSince1970
        return data.split(separator: UInt8(ascii: "\n")).compactMap { try? dec.decode(Record.self, from: Data($0)) }
    }
}
```

```swift
import FSearchKit
import Foundation
import ServiceManagement

/// Owns the daemon: use one that already answers, otherwise register the
/// bundled helper as a login item. Restarts it when asked.
@MainActor
final class DaemonManager: ObservableObject {
    enum State: Equatable { case checking, running(DaemonStatus), indexing, needsApproval, failed(String) }

    static let agentPlistName = "com.domfahey.fsearch.daemon.plist"
    @Published private(set) var state: State = .checking
    let client = DaemonClient()
    private var service: SMAppService { .agent(plistName: Self.agentPlistName) }

    func start() async {
        let answers = (try? await client.ping()) != nil
        if case .registerBundled = DaemonPlan.decide(existingAnswers: answers) {
            do { try service.register() } catch { state = .failed("Couldn't start the search helper: \(error.localizedDescription)"); return }
            if service.status == .requiresApproval { state = .needsApproval; return }
        }
        await refresh()
    }

    func refresh() async {
        for _ in 0..<50 {
            do { state = .running(try await client.status()); return }
            catch DaemonError.indexing { state = .indexing; return }
            catch { try? await Task.sleep(for: .milliseconds(200)) }
        }
        state = .failed("The search helper isn't answering.")
    }

    func restart() async {
        try? await service.unregister()
        try? service.register()
        await refresh()
    }

    func saveNow() async { try? await client.save() }

    func openLoginItems() { SMAppService.openSystemSettingsLoginItems() }
}
```

```swift
import AppKit
import UniformTypeIdentifiers

/// System file icons, cached by file type, so fast typing doesn't trigger
/// thousands of icon lookups.
@MainActor
final class IconCache {
    static let shared = IconCache()
    private var byType: [String: NSImage] = [:]

    func icon(for path: String) -> NSImage {
        let url = URL(fileURLWithPath: path)
        let ext = url.pathExtension.lowercased()
        // Folders and bundles (apps) have their own icons; ask for those directly.
        if ext.isEmpty || ext == "app" { return NSWorkspace.shared.icon(forFile: path) }
        if let cached = byType[ext] { return cached }
        let img = NSWorkspace.shared.icon(for: UTType(filenameExtension: ext) ?? .data)
        byType[ext] = img
        return img
    }
}
```

```swift
struct ResultRow: View {
    let item: ResultItem
    let query: String
    let selected: Bool

    var body: some View {
        HStack(spacing: 10) {
            Image(nsImage: IconCache.shared.icon(for: item.path)).resizable().frame(width: 22, height: 22)
            Text(highlighted(name, query)).lineLimit(1).layoutPriority(1)
            Text(detail).foregroundStyle(.secondary).lineLimit(1).truncationMode(.middle)
            Spacer(minLength: 0)
        }
        .padding(.horizontal, 12).padding(.vertical, 6)
        .background(selected ? Color.primary.opacity(0.08) : .clear, in: RoundedRectangle(cornerRadius: 8))
        .accessibilityElement(children: .combine)
    }

    private var name: String { (item.path as NSString).lastPathComponent }

    private var detail: String {
        switch item {
        case .file: (((item.path as NSString).deletingLastPathComponent) as NSString).abbreviatingWithTildeInPath
        case let .line(_, m): "\(m.line) · \(m.text.trimmingCharacters(in: .whitespaces))"
        }
    }

    private func highlighted(_ s: String, _ q: String) -> AttributedString {
        var a = AttributedString(s)
        let word = q.split(separator: " ").first.map(String.init) ?? ""
        if !word.isEmpty, let r = a.range(of: word, options: .caseInsensitive) {
            a[r].backgroundColor = .yellow.opacity(0.45)
        }
        return a
    }
}
```

```swift
                        fallback("Search inside files", "doc.text.magnifyingglass") { switchMode(.content) }
                        fallback("Find definitions", "function") { switchMode(.symbols) }
                    }

                .padding(.bottom, 6)
            }
            Divider()
            HStack(spacing: 14) {
                if app.debugMode, let us = model.lastTookUs {
                    Text(String(format: "%.1f ms · %d results", Double(us) / 1000, model.items.count)).foregroundStyle(.secondary)
                }

        Text(t).font(.system(size: 11)).foregroundStyle(.secondary).padding(.horizontal, 16).padding(.top, 10).padding(.bottom, 4)

        HStack(spacing: 10) { Image(systemName: icon).frame(width: 22); Text(t) }
            .padding(.horizontal, 12).padding(.vertical, 6).contentShape(Rectangle()).onTapGesture(perform: action)
    }

    private func hint(_ t: String, _ k: String) -> some View {
        HStack(spacing: 4) { Text(t); Text(k).padding(.horizontal, 5).overlay(RoundedRectangle(cornerRadius: 4).stroke(.secondary.opacity(0.5))) }
    }

    private func switchMode(_ m: SearchMode) {
        model.mode = m
        Task { await model.refresh() }

    private func handle(_ press: KeyPress) -> KeyPress.Result {
        state.query = model.query; state.mode = model.mode; state.count = shown.count
        let cmd = press.modifiers.contains(.command), shift = press.modifiers.contains(.shift), ctrl = press.modifiers.contains(.control)
        let key: PanelKey? = switch (press.key, cmd, shift, ctrl) {
        case (.upArrow, _, _, _), (KeyEquivalent("p"), false, false, true): .up
        case (.downArrow, _, _, _), (KeyEquivalent("n"), false, false, true): .down

        case (.delete, false, _, _) where model.query.isEmpty: .backspaceOnEmpty
        default: press.characters.first.flatMap { $0.wholeNumberValue }.flatMap { cmd ? PanelKey.cmdDigit($0) : nil }
        }
        guard let key else { return .ignored }
        let effect = reduce(&state, key)
        if model.query != state.query || model.mode != state.mode {
            model.query = state.query; model.mode = state.mode
            Task { await model.refresh() }
        }
        onEffect(effect, shown)
        return .handled
    }
```

```swift
import AppKit

/// The floating launcher: a borderless panel over every Space, centred on
/// the active screen, hidden when it loses focus.
@MainActor
final class PanelController {
    static let shared = PanelController()
    private var panel: NSPanel?
    private var session = PanelSession()
    private weak var app: AppState?

    final class Panel: NSPanel {
        override var canBecomeKey: Bool { true }
        override func resignKey() { super.resignKey(); PanelController.shared.hide() }
    }

    func install(app: AppState) {
        self.app = app
        KeyboardShortcuts.onKeyUp(for: .togglePanel) { [weak self] in self?.toggle(app: app) }
        if CommandLine.arguments.contains("-UITestShowPanel") { show(app: app) }
    }

    func toggle(app: AppState) { panel?.isVisible == true ? hide() : show(app: app) }

    func show(app: AppState) {
        self.app = app
        let resumed = session.opened(at: Date())
        app.search.query = resumed.query
        app.search.mode = resumed.mode
        let view = SearchView(model: app.search, state: resumed) { [weak self] effect, items in
            self?.perform(effect, items)
        }.environmentObject(app)
        let p = panel ?? Panel(contentRect: .zero, styleMask: [.borderless, .nonactivatingPanel], backing: .buffered, defer: false)
        p.isFloatingPanel = true
        p.level = .floating
        p.backgroundColor = .clear
        p.hasShadow = true
        p.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]
        p.contentView = NSHostingView(rootView: view)
        p.setContentSize(NSSize(width: 680, height: 460))
        if let screen = NSScreen.main {
            let f = screen.visibleFrame
            p.setFrameOrigin(NSPoint(x: f.midX - 340, y: f.midY - 30))
        }
        panel = p
        NSApp.activate(ignoringOtherApps: true)
        p.makeKeyAndOrderFront(nil)
        Task { await app.search.refresh() }
    }

    func hide() {
        guard let p = panel, p.isVisible, let app else { return }
        session.hidden(PanelState(query: app.search.query, mode: app.search.mode), at: Date())
        p.orderOut(nil)
    }

    private func perform(_ effect: PanelEffect, _ items: [ResultItem]) {
        guard let app else { return }
        switch effect {
        case .none: break
        case .hide: hide()
        case let .open(i): FileActions.open(items[i], editor: app.editorChoice); app.recents.opened(items[i].path); hide()
        case let .reveal(i): FileActions.reveal(items[i].path); hide()
        case let .quickLook(i): FileActions.quickLook(items[i].path)
        case let .copyPath(i): FileActions.copyPath(items[i].path)
        case let .showActions(i): ActionsMenu.show(for: items[i], in: panel, app: app)
        }
    }
}
```

```swift
import AppKit
import FSearchKit
import Quartz

@MainActor
enum FileActions {
    static func url(_ path: String) -> URL { URL(fileURLWithPath: path) }

    /// Default app; content hits open at their line in the chosen editor if there is one.
    static func open(_ item: ResultItem, editor: String) {
        if case let .line(path, match) = item, let e = Editor(rawValue: editor),
           let appURL = NSWorkspace.shared.urlForApplication(withBundleIdentifier: e.bundleId) {
            let c = openAtLine(e, appURL: appURL, path: path, line: match.line)
            let p = Process()
            p.executableURL = URL(fileURLWithPath: c.executable)
            p.arguments = c.arguments
            if (try? p.run()) != nil { return }
        }
        NSWorkspace.shared.open(url(item.path))
    }

    static func reveal(_ path: String) { NSWorkspace.shared.activateFileViewerSelecting([url(path)]) }

    static func copyPath(_ path: String) {
        NSPasteboard.general.clearContents()
        NSPasteboard.general.setString(path, forType: .string)
    }

    static func copyFile(_ path: String) {
        NSPasteboard.general.clearContents()
        NSPasteboard.general.writeObjects([url(path) as NSURL])
    }

    static func openWith(_ path: String, app: URL) {
        NSWorkspace.shared.open([url(path)], withApplicationAt: app, configuration: NSWorkspace.OpenConfiguration())
    }

    static func openTerminal(at path: String) {
        var isDir: ObjCBool = false
        FileManager.default.fileExists(atPath: path, isDirectory: &isDir)
        let folder = isDir.boolValue ? path : (path as NSString).deletingLastPathComponent
```

```swift
                }
            case .indexing:
                Text("Indexing your disk").font(.title3.bold())
                ProgressView().progressViewStyle(.linear)
                Text("\(entries.formatted()) files so far… usually under a minute.").foregroundStyle(.secondary)
                Text("Try it now: press your shortcut and type part of any file name.")
            }

        if let n = OnboardingStep(rawValue: step.rawValue + 1) { step = n } else { onboarded = true; NSApp.keyWindow?.close() }

    /// Facts come from the system and the daemon, never from button presses.
    private func check() async {
        switch app.daemon.state {
        case let .running(s):
            facts.helperEnabled = true
            entries = s.entries
            facts.indexReady = s.entries > 0

            if case let .running(s2) = app.daemon.state { facts.fullDiskAccess = s2.fullDiskAccess }
        case .indexing: facts.helperEnabled = true
        case .needsApproval: facts.helperEnabled = false; await app.daemon.start()
        default: await app.daemon.refresh()
        }
    }
}
```

```bash
#!/usr/bin/env bash
# Build, sign, notarize and package a release DMG plus its Sparkle appcast entry.
set -euo pipefail
: "${DEVELOPER_ID:?set DEVELOPER_ID}"
VERSION=$(/usr/libexec/PlistBuddy -c "Print CFBundleShortVersionString" App/Resources/Info.plist)
OUT=build/release
rm -rf "$OUT"; mkdir -p "$OUT"
scripts/build-daemon.sh
xcodegen generate
xcodebuild -project FSearch.xcodeproj -scheme FSearch -configuration Release -archivePath "$OUT/FSearch.xcarchive" \
  CODE_SIGN_IDENTITY="$DEVELOPER_ID" OTHER_CODE_SIGN_FLAGS="--timestamp" archive
APP="$OUT/FSearch.xcarchive/Products/Applications/FSearch.app"
codesign --force --options runtime --timestamp --sign "$DEVELOPER_ID" "$APP/Contents/Helpers/fsearch"
codesign --force --options runtime --timestamp --sign "$DEVELOPER_ID" "$APP"
codesign --verify --deep --strict "$APP"
hdiutil create -volname FSearch -srcfolder "$APP" -ov -format UDZO "$OUT/FSearch-$VERSION.dmg"
xcrun notarytool submit "$OUT/FSearch-$VERSION.dmg" --keychain-profile fsearch-notary --wait
xcrun stapler staple "$OUT/FSearch-$VERSION.dmg"
spctl -a -t open --context context:primary-signature -v "$OUT/FSearch-$VERSION.dmg"
echo "Now run Sparkle's generate_appcast on $OUT and publish appcast.xml + the DMG."
```
