# Support

## Questions

Ask questions in [GitHub Discussions](https://github.com/domfahey/fsearch-app/discussions) once Discussions is turned on for the repository.

Until then, open an issue on the [issues page](https://github.com/domfahey/fsearch-app/issues) and add the `question` label.

## Bugs

Open a [bug report](https://github.com/domfahey/fsearch-app/issues/new?template=bug_report.yml). The form asks for:

- Your macOS version and chip (Apple silicon or Intel).
- The FSearch version, or the commit if you built it yourself.
- How the fsearch daemon is installed: bundled with the app, from the CLI, or not sure.
- The steps to reproduce the problem, what you expected, and what happened.
- The output of Index Details.

To copy Index Details, open it from the menu bar with debug mode on. Click **Copy All**. Before you paste it into an issue, remove private file paths and file names.

## Feature requests

Open a [feature request](https://github.com/domfahey/fsearch-app/issues/new?template=feature_request.yml). See also [ROADMAP.md](ROADMAP.md) for what is already planned.

## Security problems

Do not open a public issue for a security problem. Follow [SECURITY.md](SECURITY.md) to report it privately.
